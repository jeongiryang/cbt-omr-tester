# CBT OMR 테스터

![CBT Preview](./screenshot.png)

브라우저에서 시험 조건을 설정하고 OMR 답안을 작성한 뒤 즉시 채점할 수 있는 단일 HTML 기반 CBT 도구입니다.

## 주요 기능

- 과목 수, 과목명, 과목별 문항 수를 자유롭게 설정
- 4지선다 또는 5지선다 선택 및 문항별 배점 또는 100점 자동 배점 지원
- 과목별 OMR 답안 마킹과 실시간 응답 진행률 표시
- 과목별 정답 입력 후 자동 채점, 총점과 과목별 점수 제공
- 전체 합격 기준과 과목별 과락 기준을 함께 판정
- 오답·미응답 문항과 정답을 한눈에 확인

## 미리보기 갱신

```bash
npm install
npm run capture
```

위 명령은 Playwright와 헤드리스 Edge를 사용해 프로젝트 루트의 `screenshot.png`를 갱신합니다.
